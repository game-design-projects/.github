# .github

Org-level repository for [game-design-projects](https://github.com/game-design-projects).

- `profile/README.md` is rendered on the organization's home page. The project table between the `REPOS` markers is rewritten daily by [`update-profile.yml`](.github/workflows/update-profile.yml) (also runnable on demand via *Run workflow*).
- Only **public** repos are listed; forks, archived repos and the meta repos (`.github`, `*.github.io`) are skipped.
